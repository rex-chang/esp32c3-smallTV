# Token Plan 显示调整记录

## 2026-05-21

- 问题：Token Plan 页面在 240x240 屏幕上使用 `ZdyLwFont_20` 显示 3 张卡片，标题、进度条、token 用量文本互相挤压，实机出现左侧裁切和文字重叠。
- 调整：Token Plan 页面改用 TFT_eSPI 内置小字体绘制标题、服务名、百分比和进度条；每页最多显示 3 个服务，超过数量在底部提示。
- 调整：卡片内不再显示 `used / limit tokens`，只显示百分比，避免小屏文本拥挤。
- 注意：`/token` 接口仍接收 `used` 和 `limit`，用于计算百分比和进度条。

## 2026-05-21 补充

- 问题：内置小字体不支持中文服务名，实机显示中文异常；同时 3 条数据时页面留白偏多。
- 调整：Token Plan 页面恢复加载 `ZdyLwFont_20`，服务名支持中文渲染；卡片背景、边框和进度条加粗，提升信息密度。
- 调整：服务名按像素宽度截断，并按 UTF-8 字符边界删除，避免中文被截断成乱码。

## 2026-05-21 刷新策略

- 问题：Token Plan 模式每分钟刷新时间时调用整页 `displayToken()`，函数内执行 `tft.fillScreen()`，实机会出现每分钟一次全屏闪烁。
- 调整：新数据到达或切换显示模式时整页重绘；仅分钟变化时只重绘顶部时间栏，避免整屏闪烁。
- 问题：设备重启后 `setup()` 无条件初始化天气页面，导致 Token 顶栏下方残留城市、天气图标和温湿度。
- 调整：启动初始化按 `DISP_mode` 分支，Token Plan 模式只绘制 Token 页面，天气模式才绘制天气组件并拉取天气数据。
- 调整：页面标题从 `TOKEN PLAN` 改为 `USAGE LIMITS`。
- 调整：超过 3 个服务时改为分页循环显示，每页 3 个，8 秒自动切换下一页；底部显示 `当前页/总页数 + 更新时间`。
- 调整：分页切换改为擦除 + 低亮度淡入 + 正常亮度重绘，仅作用于 30px 以下内容区。
- 调整：分页过渡动画速度放慢约 2 倍，擦除步进延时 36ms，淡入停留 140ms。
- 调整：标题栏拆成标题视窗和时间视窗，标题支持横向滚动，避免长标题覆盖时间区域或出现边界乱码。
- 调整：服务名超宽截断时不再追加 `~`，因为当前字库缺少该字形，实机会显示成小方块。
